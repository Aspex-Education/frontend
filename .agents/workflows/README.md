# Agents Configuration (ASDD)

This directory contains the specifications and instructions for AI agents to follow during the development of the Aspex Education Frontend.

## Agent Instructions
- **ARCHITECTURE.spec.md**: Defines the system architecture and data flow.
- **FRONTEND_WORKFLOW.md**: Guidelines for creating components, managing state with Signals, and testing.
- **IMPLEMENTATION.md**: Specific implementation details and patterns.
- **SECURITY.md**: Security protocols and best practices.

## How to use
When working with AI agents, always reference these files to ensure consistency with the project's standards.
